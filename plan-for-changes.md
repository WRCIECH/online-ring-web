# Plan for Changes


Each weapon will have three modes right now: micro, medium and heavy.
Micro mode corresponds to publishing short form.
Medium corresponds for working on and publishing medium form.
Heavy correspond for working on heavy form
Accomplishign a campaign require to finish micro, medium and heavy (micro means going one circle, medium - going through all products, and heavy - just finishing this one big product).

Micro Mode
Micro products: Text, Graphic, Carousel, Video, Audio, LinkShare(Repost/Recycle)
Micro Audience products: Poll, Question, Reply, DM (currently hidden - to be activated later)
Style (for Micro): shock, narration, segmentation, passion, esthetic, cliffhanger, viral, controversy, comfort, drama, humor, parasocial, wow, hope, fear, desire, critique

Each weapon we draw micro mode. Micro mode is a circle of products to generate. For example for a given weapon we draw 8 micro products to create and we assign for each one product type (e.g. text) and style (with probability 50% - so 50% are without style attached).
Circle means that after publishing one micro product we go to the next and so on. When we go with all of them we go back to the first one.

Micro mode does not have timer - if we publish a content - we just mark it as done and we do dmg to mob. This attract should be equal to dmg of heavy attack.

Medium Mode
Medium products: Text, Audio (Podcast), Video, Interview, Commentary, Infographic, Carousel
Audience (for later): Livestream, Q&A

Medium mode will have for each weapon 2 levels products: level 1 and level 2. E.g for given weapon first each pieces are text and then in the level 2 we have video version. Make note that we should be able to create level to produce for a given content piece after level one was accomplished. So doing level 1 content piece unlocks level for for this content piece but also unlocks next content piece in a linear sequence.

Currently in weapon campaign we draw content pieces in a tree form. Instead I want to have this linear.
How many content pieces for medium? Maybe 8-15.

The following links can be assigned to the link between contents:
Content-shift: follows (50%), zoom-in (15%), zoom-out (15%), similar (15%), opposite (5%)

Additionally there will be a node constraint
Constraints:
Propaganda-shift: enhance, weaken, focus(explain), action
Audience-shift: audience-x, lower-self, average-self, higher-self, base/trend/event, need/identity/belief
Style-shift: narration, segmentation, socratic, enemy(hero), slogan(symbol), analogy, verbose(expansion), succinct (compression), analogy, technicalize, simplify, evidence, data-driven, first-principles

Compression rename to Succint
Expansion rename to Verbose
The following should be removed: split, localize, remove domain-shift, problem-solving


Heavy Mode

Heavy Products: Text, Video, AssetPack, CurationFeed, Application, Website, Experimental, Course, Book

Audience (for later): CommunityProject, CommunitySpace, Event, Challenge, BehindScenes, Platinum Offer, 

Modes of work: Research/Work.

For heavy mode we draw how many research and work tiles we will have for work on the product e.g. 15 research and 15 produce. We can switch between research/produce if we want. After doing all of them but when we still have not finished research/produce we can repeat tiles with penalty of dmg (this is already implemented).
